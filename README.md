# Web综合项目：待办清单系统
## 项目简介
原生HTML+CSS+ES6 JS实现移动端优先响应式待办清单。

## 功能清单
### 必做功能
1. 3个页面：首页index.html、列表list.html、详情detail.html
2. HTML5语义标签 header nav main section footer
3. 响应式布局，手机<768px单列，桌面>=768网格布局，媒体查询+Flex/Grid
4. 新增待办表单，前端校验标题长度、内容长度
5. JS动态渲染任务列表、搜索、筛选（全部/已完成/未完成）
6. 任务增删改交互

### 提高选做功能
1. LocalStorage持久化存储，刷新页面数据不丢失
2. Fetch读取本地data.json加载初始示例数据
3. 用户注册/登录，待办数据按用户隔离存储

## 运行方式
1.VSCode打开项目文件夹，安装Live Server插件
2.右键index.html，Open with Live Server，浏览器访问运行。
3.首次打开会跳到登录页，先注册一个账号再登录（未登录访问任意页面都会跳回登录页）。
